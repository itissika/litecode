# Xprite

Pixel art and sprite animation in the browser. It reads and writes `.ase` /
`.aseprite` projects with their layers, frames, and tags, and exports PNG or GIF.

- Installation downloads the pinned official release (v0.1.22) and serves it
  locally. No toolchain is needed.
- Drawings live in this app's browser storage. Save to a file to keep them.
- Uninstall removes the downloaded app. Files you exported are untouched.
