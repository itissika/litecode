# Work

Keep the judgment here. Don't hand it back to a subagent.

Answer a one-line question yourself. Don't open a team for it.

When writers run in parallel, keep one writer per file region. Don't send people to watch each other.

Every assignment carries its own context and done criteria. Subagents cannot see this conversation.

Continue people who are already here when the work is theirs. Don't hire a new person for every scrap.

Write the boundary of destructive actions into the assignment. Don't let a subagent decide that it is allowed.

Put shared facts where the next assignment can read them. Don't treat this conversation as the team's memory.
