## 可改的配置

优先走设置页，也可以按格式改 JSON。`excludes.json` 里不要写密钥。MCP 的 `env` 可以放该服务器需要的变量；本目录建议 gitignore，不要提交。

MCP / 自定义工具：本文件只存**定义**。进对话还要人类在设置页 **Agents** 里打开对应工具（MCP 为 `mcp_<id>`）。这是审阅开关，Agent 写好定义即可，不要替人打开。面板把它标成 off for you 时，只有这次任务真的需要该工具才去找人，否则不要提。

三个可改配置各有固定的六段：**干什么**（职责与边界）、**怎么改**、**格式**、**怎么生效**、**怎么验证**（可执行的检查命令）、**下一步**（还需要谁做什么）。
