`code` is plain JavaScript. The TypeScript declarations below are documentation only; do not copy type annotations into `code`.
The bundled tools declared below are reachable only through the generated `tools` object inside `code`; they are not separately callable. Other LiteCode tools are outside this SDK and may remain directly callable according to the registry. `libs` contains deterministic pure-JavaScript analysis helpers and exposes no filesystem, network, or process API. Standard JavaScript built-ins are available.
A call resolves to the tool's data. A domain failure rejects `ToolError`. Its `code` is one of `invalid_input`, `not_found`, `invalid_regex`, `stale`, `stale_cursor`, `conflict`, `permission_denied`, `timeout`, `io`, `unsupported`, `edit_failed`, `internal`. A protocol failure (an extra argument, an illegal value, nesting that is too deep, an integer above 2^53-1, or the in-flight cap) throws `TypeError`. Cancellation, the `run_code` budget, the output cap, and memory or stack limits end the program and cannot be caught.
Permission denial is a catchable `ToolError` whose `code` is `permission_denied`.
An edit that writes some blocks and fails others resolves. Check `failed` and `blocks`. An edit that writes nothing rejects `ToolError` with `code` `edit_failed`.
Use `Promise.allSettled` for a batch. One uncaught rejection ends the program and cancels the other in-flight calls.
LSP errors from edit or write are not in the resolved data. They appear only in this run's outer text.
A read of session lines already in the context window returns empty `lines` with `reason` `"in_context_window"`.
A glob that matches nothing returns `reason` `"no_match"`. A glob whose path is hidden by the default filters returns `reason` `"path_excluded"`.
The model sees about 64KB of this run. Return a summary, not a raw bulk of data.
Call each binding as `tools["name"](args)`. When `name` is an identifier, `tools.name(args)` is the same function. Each binding takes one argument object. Tool timeouts are internal. The only budget the program sets is `run_code`'s `timeout_ms`.
Return a JSON-serializable value: `undefined` is not JSON, so use `null` or omit the property.

declare class ToolError extends Error {
  readonly name: "ToolError";
  readonly code: string;
  readonly details?: unknown;
  readonly retryable?: true;
  readonly tool: string;
  readonly seq: number;
}

type EditInput = {
  // Replacements to apply to this file.
  edits: Array<{
    // Replacement text. Use an empty string to delete old_string.
    new_string: string;
    // File text to find. Do not include read's line-number prefix. Must match one place unless replace_all is true; add surrounding lines if it appears more than once.
    old_string: string;
    // Replace every exact occurrence (default: false).
    replace_all?: boolean;
  }>;
  // Prefer a workspace-relative path; absolute paths outside the workspace are allowed only under All permission. On Windows use C:\...; Unix-style /paths map under Git for Windows when installed.
  path: string;
  // sha256 of the file bytes from a previous read. Omit to skip the check. A mismatch rejects stale and does not write.
  expected_hash?: string;
};

// Blocks applied to one file. file is the identity after the successful blocks were written.
type EditData = {
  // Number of blocks written.
  applied: Integer;
  // One result per edit, in input order. Failed blocks do not roll back applied blocks.
  blocks: Array<{
    // 1-based index in edits.
    index: Integer;
    ranges: Array<{
      end_line: Integer;
      start_line: Integer;
    }>;
    status: "applied" | "failed";
    // Present when status is failed.
    reason?: {
      code: string;
      message: string;
      // Structured cause. Fields appear only for the reason that produced them.
      details?: {
        kind?: "identical_strings" | "replacement_unchanged" | "leading_trailing" | "internal_spacing" | "input";
        // One line of the file the whitespace difference pointed at.
        excerpt?: string;
        lines?: Array<Integer>;
        other_index?: Integer;
        other_range?: {
          end_line: Integer;
          start_line: Integer;
        };
        prior_index?: Integer;
      };
    };
  }>;
  // Number of blocks not written.
  failed: Integer;
  // File identity after the write. path is workspace-relative inside the workspace. Outside the workspace, path is the requested path and abs is absolute.
  file: {
    bytes: Integer;
    // sha256 hex of the file bytes.
    hash: string;
    path: string;
    abs?: string;
  };
};

type GlobInput = {
  // Glob relative to path (or workspace root if path omitted). Example: '**/*.rs'. The pattern is used as given; a repeated path prefix is not removed. If path is 'src', use '**/*.rs', not 'src/**/*.rs'.
  pattern: string;
  // Opaque continuation from a previous glob page. Bound to pattern, path, and filters. A different query rejects stale_cursor.
  cursor?: string;
  // Also search gitignored and workspace-excluded paths. Default false.
  include_ignored?: boolean;
  // Maximum paths in this page. Default 1000, maximum 5000.
  limit?: Integer;
  // Optional directory to search under (workspace-relative preferred; absolute paths outside the workspace only under All permission). Pattern is matched relative to this directory. Session transcripts are listed only when this is `.litecode/sessions`.
  path?: string;
};

// One page of matching paths.
type GlobData = {
  // workspace: paths are workspace-relative. absolute: paths are absolute.
  base: "workspace" | "absolute";
  page: {
    has_more: boolean;
    next: string | null;
    total?: Integer;
  };
  // Matching paths sorted by depth, then parent directory, then name. Pass a path to read.
  paths: Array<string>;
  // no_match: nothing matched. path_excluded: the path is hidden by the default filters.
  reason?: "no_match" | "path_excluded";
};

type GrepInput = {
  // Regular expression over file contents, unless literal is true.
  pattern: string;
  // Default true. Set false to ignore case.
  case_sensitive?: boolean;
  // Continuation from data.page.next. Bound to pattern, path, glob, filters, and the corpus version. A different query rejects stale_cursor.
  cursor?: string;
  // Filter which files to search: one glob, or a comma-separated list. A leading ! excludes. Relative to path.
  glob?: string;
  // Also search gitignored and workspace-excluded paths. Default false.
  include_ignored?: boolean;
  // Maximum matches in this page. Default 20, maximum 100.
  limit?: Integer;
  // Search for pattern as plain text. Default false.
  literal?: boolean;
  // File or directory to search. Defaults to the workspace. Outside the workspace, returned paths are absolute so read can open them.
  path?: string;
};

// One page of content matches.
type GrepData = {
  base: "workspace" | "absolute";
  matches: Array<{
    end_line: Integer;
    line_text: string;
    line_truncated: boolean;
    path: string;
    start_line: Integer;
  }>;
  page: {
    has_more: boolean;
    next: string | null;
    total?: Integer | null;
  };
  searched: {
    // True when default exclusion filters were active, or the path itself was excluded.
    excluded: boolean;
    files: Integer;
  };
  reason?: "no_match" | "corpus_empty" | "glob_empty" | "path_excluded" | "binary_file" | "file_not_searched";
};

type ReadInput = {
  // Prefer a workspace-relative path; absolute paths outside the workspace are allowed only under All permission. On Windows use C:\...; Unix-style /paths map under Git for Windows when installed. Past session transcripts are readable at `.litecode/sessions/<session_id>.md`.
  path: string;
  // Last line to read, 1-based, inclusive. The page ends at min(end_line, start_line + limit - 1).
  end_line?: Integer;
  // Maximum lines in this page. Default 2000, maximum 5000.
  limit?: Integer;
  // First line to read, 1-based, inclusive. Default 1.
  start_line?: Integer;
};

// One page of a text file, with the file's sha256 identity.
type ReadData = {
  // File identity. path is workspace-relative inside the workspace. Outside the workspace, path is the requested path and abs is absolute.
  file: {
    bytes: Integer;
    // sha256 hex of the file bytes.
    hash: string;
    path: string;
    abs?: string;
  };
  // Lines in this page, in file order.
  lines: Array<{
    // True when text was capped at the per-line character limit.
    line_truncated: boolean;
    // 1-based line number.
    number: Integer;
    // Line text without a line-number prefix.
    text: string;
  }>;
  page: {
    // True when any line remains after this page, including after an explicit window.
    has_more: boolean;
    // Next 1-based line number, or null when the file is finished.
    next: string | null;
    // Total lines in the file.
    total?: Integer;
  };
  // Set when lines is empty because those session lines are already in the context window.
  reason?: "in_context_window";
};

type WriteInput = {
  // Content to write to the file
  content: string;
  // Prefer a workspace-relative path; absolute paths outside the workspace are allowed only under All permission. On Windows use C:\...; Unix-style /paths map under Git for Windows when installed.
  path: string;
  // If true, refuse to overwrite an existing file (default: false)
  create_only?: boolean;
  // sha256 of the current file bytes. Omit to skip the check. A mismatch rejects stale and does not write. Together with create_only, a missing file rejects invalid_input.
  expected_hash?: string;
};

// File that was written.
type WriteData = {
  // True when the file did not exist before.
  created: boolean;
  // File identity after the write. path is workspace-relative inside the workspace. Outside the workspace, path is the requested path and abs is absolute.
  file: {
    bytes: Integer;
    // sha256 hex of the file bytes.
    hash: string;
    path: string;
    abs?: string;
  };
};

declare const tools: {
  // Replace text in one file. The result is `data.file`, `data.blocks`, `data.applied`, and `data.failed`. `data.file` is the identity after the successful blocks are written (`path`, `hash`, `bytes`, and `abs` outside the workspace). Each block is `index`, `status` (`applied` or `failed`), `ranges` (`start_line`, `end_line`), and `reason` (`code`, `message`, optional `details`) when it failed. Optional `expected_hash` is the sha256 from `read` `data.file.hash`. Omit it to skip the check. A mismatch rejects `stale` with `details.current_hash` and does not write. All blocks match the file before any of them apply. A partial failure resolves: check `failed` and `blocks`. The blocks that matched are written. No block applied rejects `ToolError` with `code` `edit_failed` and `details.blocks`; the file is not modified.
  //
  // Multiple files means multiple calls, one path each. Pass `path` and a non-empty `edits` array; each item is `old_string`, `new_string`, and optional `replace_all` (default false). Empty `new_string` deletes `old_string`. Matching is exact. CRLF and LF compare equal, and a leading UTF-8 BOM is preserved. `replace_all` replaces every exact occurrence. A block that matches more than once without `replace_all` fails only that block. When other blocks are written the call still resolves, and the failed block's `reason.code` is `multiple_matches`. When no block is written the call rejects `ToolError` with `code` `edit_failed`.
  // All edits in one call match the file before any of them apply. Independent edits can share a call; if a later old_string depends on an earlier new_string, submit it in a later edit call.
  // Example (one edit): {"path":"src/a.rs","edits":[{"old_string":"fn start() {}","new_string":"fn main() {}"}]}
  // Example (several): {"path":"src/a.rs","edits":[{"old_string":"foo","new_string":"bar"},{"old_string":"old_api(","new_string":"new_api(","replace_all":true}]}
  readonly ["edit"]: (args: EditInput) => Promise<EditData>;
  // Find files by path glob. The result is `data.base`, `data.paths`, and `data.page`. `paths` are sorted by depth, then parent directory, then name. When `base` is `"workspace"`, each path is workspace-relative and can be passed to read. When `base` is `"absolute"`, each path is absolute and can be passed to read.
  //
  // `pattern` is matched relative to `path` exactly as given. A directory prefix that repeats `path` is not removed. With `path` `src`, use `pattern` `**/*.rs`, not `src/**/*.rs`. A pattern that reaches outside the search directory, including `..`, rejects `invalid_input`. `limit` defaults to 1000 and is at most 5000. When `data.page.has_more` is true, pass `data.page.next` back as `cursor`. The cursor is bound to this pattern, path, and filters. A different query rejects `ToolError` with `code` `stale_cursor`. Default filters hide gitignored and workspace-excluded paths; set `include_ignored` true to include them. No matches set `data.reason` to `no_match`. A path hidden by those filters sets `data.reason` to `path_excluded`. For content matches use grep.
  readonly ["glob"]: (args: GlobInput) => Promise<GlobData>;
  // Search file contents. The result is `data.base`, `data.matches`, `data.page`, `data.searched`, and sometimes `data.reason`. Matches are `{path, start_line, end_line, line_text, line_truncated}`. Read the file for surrounding lines.
  //
  // `pattern` is a regular expression unless `literal` is true. An invalid pattern rejects `invalid_regex`. Pass `literal: true` to search for the pattern as plain text. A blank `glob` rejects `invalid_input`.
  //
  // The default corpus applies workspace search exclusions and `.gitignore`. Set `include_ignored` true to search gitignored and workspace-excluded paths. `limit` is 1-100 and defaults to 20. When `data.page.has_more` is true, pass `data.page.next` back as `cursor`. The cursor is bound to this pattern, path, glob, filters, and a corpus version. A different query, or the same query after the files change, rejects `ToolError` with `code` `stale_cursor`. A capped match line sets `line_truncated`. An empty result sets `data.reason` to `no_match`, `corpus_empty`, `glob_empty`, `path_excluded`, `binary_file`, or `file_not_searched`.
  //
  // Example: {"pattern":"fn main","path":"src"}
  readonly ["grep"]: (args: GrepInput) => Promise<GrepData>;
  // Read one workspace file as structured data. Use `data.file` and `data.lines`. Images and other non-UTF-8 files reject `ToolError` with `code` `unsupported`. `details` has `path`, `mime`, and `bytes`.
  //
  // `path` is the file. `start_line` and `end_line` select a 1-based inclusive window and must be integers >= 1; any other value rejects `invalid_input`. A missing file rejects `not_found`. `limit` is the page size in lines (default 2000, maximum 5000). The page ends at `min(end_line, start_line + limit - 1)`. There is no cursor parameter and no token budget. `data.page.has_more` is true when any line remains after this page, including after an explicit window. `data.page.next` is the next 1-based line number as a string, or null when the file is finished. Pass it back as `start_line`. A capped line sets `lines[].line_truncated` only. `data.file.hash` is the sha256 of the file bytes; pass it to edit as `expected_hash`. Past session transcripts are readable at `.litecode/sessions/<session_id>.md`. Lines of this session that are already in the context window come back as empty `lines` with `reason` `in_context_window`. For discovery by name use glob; for content search use grep.
  readonly ["read"]: (args: ReadInput) => Promise<ReadData>;
  // Create a new file or overwrite an existing one. The result is `data.file` and `data.created`. `data.file` is the identity after the write (`path`, `hash`, `bytes`, and `abs` outside the workspace). `data.created` is true when the file did not exist before. Optional `expected_hash` is the sha256 of the current bytes. Omit it to skip the check. A mismatch rejects `ToolError` with `code` `stale` and `details.current_hash`, and does not write. If the file is missing, `expected_hash` alone rejects `not_found` and does not create the file. `create_only` on an existing file rejects `conflict`. `create_only` together with `expected_hash` when the file does not exist rejects `invalid_input` and does not create it. A path outside the workspace, and LSP errors in the written file, appear only in this run's outer text. Prefer edit for a surgical change in an existing file.
  readonly ["write"]: (args: WriteInput) => Promise<WriteData>;
};
