Semantic code search over the workspace index for wide discovery by meaning or topic (where auth lives, how retries work). The corpus is the suffix allowlist in Settings → Files (`code_index_extensions`); changing `search_exclude` does not change it. Prefer grep for exact symbols/strings and glob for path patterns. Only available when retrieval is enabled (Settings → Engines) and the code_search engine is Warm — while Warming or disabled the tool is hidden. Results begin with a sync_pct line showing index sync progress.
