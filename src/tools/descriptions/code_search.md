Semantic search over the workspace code index by meaning or code identifier. Returns ranked source snippets with workspace path, anchor line, exact snippet line range, and an optional AST symbol. One query per call; there is no paging. Optional `include_pattern`, `top_k` (default 8, max 20), and `min_score` (raw dense cosine, default 0.80, 0 disables the floor) constrain the query. The corpus is the suffix allowlist in Settings -> Files (`code_index_extensions`); changing `search_exclude` does not change it. Engine off, warming, failed, and busy outcomes resolve with `ok: false` and a `status` so a program can branch.
