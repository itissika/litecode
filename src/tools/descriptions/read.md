Read one workspace file as structured data. Use `data.file` and `data.lines`. Images and other non-UTF-8 files fail with `error.code` `"unsupported"` and `details` `path`, `mime`, and `bytes`.

`path` is the file. `start_line` and `end_line` select a 1-based inclusive window. `limit` is the page size in lines (default 2000, maximum 5000). The page ends at `min(end_line, start_line + limit - 1)`. There is no cursor parameter and no token budget. `data.page.has_more` is true when any line remains after this page, including after an explicit window. `data.page.next` is the next 1-based line number as a string, or null when the file is finished. Pass it back as `start_line`. A capped line sets `lines[].line_truncated` and adds diagnostic `line_truncated`. `data.file.hash` is the sha256 of the file bytes; pass it to edit as `expected_hash`. Past session transcripts are readable at `.litecode/sessions/<session_id>.md`. For discovery by name use glob; for content search use grep.
