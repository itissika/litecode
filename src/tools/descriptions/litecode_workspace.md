Facade for this workspace: excludes, MCP servers, custom tools, apps, and sessions. `refresh` (and `refresh all`) validates excludes, MCP, and custom tools. An MCP server or custom tool that is off for you stays quiet unless you actually need it. `apps` (or `apps <id>`) lists every built-in and custom app with its install state, URL, data dir, and last install/runtime error; it is read-only and never installs, trusts, or starts. Call `guide apps` before editing `.litecode/apps.json`; use `apps` to inspect state and errors. It does not write files, enable tools, or start engines. Omit `action` to open the panel.

`validate_custom` trials a custom tool without registering: pass definition + sample_input alongside action. It reports definition, code-surface admission, and process/envelope failures separately. Use surface `direct` for standalone/background/media tools and `code` for tools called inside run_code; code tools return `{ok,text}` and cannot use run_in_background.
