Create a new file or overwrite an existing one. The result is `file` and `created`. `file` is the identity after the write (`path`, `hash`, `bytes`, and `abs` outside the workspace). `created` is true when the file did not exist before. Optional `expected_hash` is the sha256 of the current bytes. Omit it to skip the check. A mismatch resolves `ok: false` with `reason` `stale` (and `details.current_hash` on the underlying error), and does not write. If the file is missing, `expected_hash` alone resolves `ok: false` with `reason` `not_found` and does not create the file. `create_only` on an existing file resolves `ok: false` with `reason` `conflict`. `create_only` together with `expected_hash` when the file does not exist resolves `ok: false` with `reason` `invalid_args` and does not create it. LSP errors from the written file are not in the resolved data—log or return them if you need them visible.
