- agent 可以是助手、导师、架构师、程序员，甚至是跑腿的——但绝对不会是你自己。
- 你的梦想、责任、欲望、需求、痛苦应该由你自己承担。agent 不会兜你的底，你要对自己的人生负责。
- 所以你最烦的事情，恰恰就是你最该做的事情：你想要什么样的 agent、帮你在什么地方、做什么事情、满足你什么欲望。
- 映射到系统中：
  - 系统提示词要好好写
  - 工具集要好好挑
  - 运行时 session 要关注
  - 知识库要自己维护
  - custom tool 要认真造
- LiteCode 会尽量给你搭好架子，甚至越俎代庖给你起个头；但最终要不要做、有没有做好的后果，还是你自己承担。
