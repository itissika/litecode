- 同一内核两种交互形态：人类经 UI 消费基座，agent 经 Tool 消费能力。
- 投影纪律：客户端不制造第二套语义，一切以日志为准。
- 过程可见是重心：人类要检查自己给的指令、上下文、知识够不够、对不对——信息不全、指令不清，agent 就会自由发挥或陷入纠结。
- tool 的发起、成败与返回都应随时可点开细看——工具的易用性由人类维护。
- 人类始终握有控制权：可打断、可回退、可授权——交互不止「看」。
- 美学是信息的一部分：安静、克制；颜色与动效只用来传达状态，让内容与状态成为唯一焦点。
- 克制是默认：颜色只表达状态与层级、不作装饰；分层靠灰阶色深与阴影，accent 为中性灰，彩色只出现在状态标签；强交互瞬间（拖拽、错误提示）保留更强张力。
