**主张：** 工具实现可以各异，但接入公共管线时遵守同一套实现契约。

- 身份与接口：声明 name 与 schema，schema 决定参数如何被校验与呈现。
- 业务实现：专注做好这件事本身，描述说明它要做什么，但不独自裁决授权。
- 并发与资源：声明并发安全与占用的资源，供公共编排判断可否并行。
- 结果返回：按共同结果契约返回业务结果与信号，不自造方言。
- 接入方式：内置、Custom、MCP 只是接入方式不同，不构成绕过公共契约的理由。
