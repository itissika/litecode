```node
node : tool-output-shaping
status : enabled
summary : 结果只有一处出口，目标三个：token 效率、边界即指引、绝对一致。
x : 2394
y : 486
w : 326
h : 346
domain : tools-permission
```

**解决什么：** 模型看不见工具，只看得见结果，结果怎么写，决定了它花多少 token、要不要返工、下一步走得对不对。

**高密度的 token 效率：** 同等信息量级下，token 消耗更低。

- 控制每步最大量：工具在自己的粒度上直接截断，`run_code` 管线统一截断落盘。
- 管线自动选渲染：compact JSON，结构化数据自动整形为表格。
- 渲染器对工具粒度做专项优化：read 的行体、exec_command 的 output 按原样给，不套 JSON。
- 同一个事实只出现一次：路径不重复，列表压成标签。

**边界即指引：** 碰到边界时，「碰到了什么」和「接下来怎么办」是同一条结果。

- 边界形状固定：不存在、拒绝、超时、取消、部分成功、超限、媒体、编码失败。
- 提醒要克制：数据本身能说明白的，不再重复提醒、不再给指引；空只是最常见的一例。
- 正文只写事实；碰到边界时，下一步以提醒形式上浮，挂在调用号下，不混进正文。
- 提醒里给的是：续页传什么参数、缺口在第几行、完整文件在哪、哪个参数错了、能不能重试、值被夹紧了多少、数据可能不完整。

**绝对一致：** 同一类信息永远同一种写法，不只是行号。

- 坐标：文件行 1-based，命中 offset 0-based，不混用；列不进视图。
- path、标签、前缀、结构也各有唯一写法，模型不用为每个工具重学一套语法。
- 出口幂等：同一条结果被重复整形，结果不变，不会长出第二层 `Error:` 或第二段 `Hint:`。

**绝对不允许：**

- 工具自己拼 `Error:` / `Warning:` / `Hint:`。
- 工具自己截断、自己落盘、自己发明省略号。
- 工具自己物化媒体，或把没物化的句柄当成功结果交出去。
- 为某个工具发明第二套结果语法。
- 报边界只说「失败了」，不给下一步。

**收尾的一句：** 结果是模型唯一的证据来源；省下的 token，要么是下一步的指引，要么留在可再取的地方。
