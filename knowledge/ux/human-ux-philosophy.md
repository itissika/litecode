**暴论：人类消费工作区基座，agent 消费 Tool——同一内核，两种交互形态。**

- 人类与 agent 不是两个产品：agent 经 Tool 管线消费能力，人类经 UI 消费同一批共享基座（文件 / 终端 / 引擎 / 搜索 / Git）；入口各自特化，实例共享 [@ id="workspace-shared-substrate" label="工作区基座"]。
- 设计目标：安静、专业、低认知负荷的工具型界面；agent 过程默认可见而不打扰 [@ id="process-visibility" label="过程可见"]。
- 客户端是内核真源的投影，不得发明第二套对话语义 [@ id="ui-projection-only" label="客户端只做投影"]。
- 交互三层：纯人类 / 人机协作 / 纯 agent 可观测 [@ id="interaction-three-layers" label="三层交互模型"]；协作靠卡片 [@ id="collaboration-cards" label="协作卡"]。
- 结构：可停靠布局 [@ id="ux" label="ux"]、克制视觉 [@ id="ux-design" label="ux 设计"]。
