## 统一 WP 模型（本包要落地的规则）
1. 每个 WP 结构完全一致：goal（上级给）、内容（负责人填：直接执行内容，或带 goal 的子包）、负责人、上级审批人、状态、产物。
2. 流程每层相同：上级给 goal → 负责人填内容/拆子包 → 向上请审 → 批准后才执行/往下派 → 执行完封包 → 向上交回。
3. 子包只感知自己的 goal 和平级包，不必感知父包（工具里可查，但不强制）。
4. 子包由该层负责人自己建；上级不替下级建子包。
5. 父包送审前，子包须全部封为 done 或 blocked；blocked 的父包要等上级点头后才能关。
6. 审批没通过就退回填写人改；被打回的父包可以指定重开某个子包。
